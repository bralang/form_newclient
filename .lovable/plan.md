
## המטרה
להגדיל משמעותית את "מפת השליטה בחברה" שמופיעה בעמוד 2, כדי שתהיה ברורה וקריאה הרבה יותר.

## שינויים מתוכננים

### 1. `src/components/FormLayout.tsx` — שינוי מבנה העמודות בדסקטופ
- העמודה השמאלית (שמכילה את העץ + הדמותג + יצירת קשר + "לתשומת ליבכם") תורחב מ-`w-64 xl:w-72` ל-`w-[26rem] xl:w-[32rem]` — כמעט פי 2.
- העמודה של הטופס תצטמצם בהתאם (`max-w-3xl` → `max-w-2xl`) כדי לפנות מקום למפה.
- מפת השליטה תקבל את רוב הגובה: `flex-1` עם `overflow-y-auto`, במקום `mt-auto` שדוחף הכל למטה. הדמותג + יצירת קשר ירדו לחלק תחתון קומפקטי יותר (דמותג `h-40` במקום `h-56`).

### 2. `src/components/OwnershipTree.tsx` — הגדלת הרכיב עצמו
- כותרת "מפת השליטה בחברה": מ-`text-xs` ל-`text-base font-bold`, אייקון `w-5 h-5`.
- padding של המיכל: מ-`p-3` ל-`p-5`.
- max-height: מ-`max-h-[55vh]` ל-`max-h-[70vh]`.
- כרטיסיות הצמתים (`TreeNodeView`):
  - text מ-`text-[11px]` ל-`text-sm`
  - padding מ-`px-2 py-1` ל-`px-3 py-2`
  - אייקונים מ-`w-3.5 h-3.5` ל-`w-4 h-4`
  - אחוזים מ-`text-[10px]` ל-`text-xs`
  - תגיות "חדשה" מ-`text-[9px]` ל-`text-[11px]`
- מרווחים בין רמות: `mr-3 pr-2 space-y-1.5` → `mr-5 pr-3 space-y-2.5`, וקו ההיררכיה `border-r-2` → `border-r-[3px]`.
- מקרא (legend): גופן מ-`text-[9px]` ל-`text-[11px]`, וריבועי הצבע מ-`w-2 h-2` ל-`w-3 h-3`.
- במצב מובייל (`compact`) — נשאיר מעט יותר קומפקטי אבל גם שם נגדיל בערך 30%.

### 3. אין שינוי בלוגיקה
- מבנה הנתונים, התוכן, וההיררכיה נשארים בדיוק כפי שהם — רק גודל ויזואלי.

## תוצאה צפויה
מפת השליטה תתפוס נתח משמעותי מהעמודה השמאלית בדסקטופ, הטקסט יהיה קריא בנוחות גם בשרשורים עמוקים, והמשתמשת תוכל לעקוב אחרי מבנה האחזקה ויזואלית בלי להתאמץ.
